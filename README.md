# GengarIRT

**GengarIRT** = **G**engar **I**nternet **R**equests-**P**romoter **T**ransformer

Самообучающийся "ИИ" без API и готовых моделей. Генгар ничего не знает заранее: каждое новое слово он сам изучает запросами в интернет, а потом копит знания у тебя на компьютере и отвечает уже из памяти.

## Что это такое

GengarIRT - фундаментально другой ИИ. В нём нет API и готовых нейросетей: он работает без них и анализирует каждое слово (индекс) прямо в интернете, сразу на нескольких сайтах. Словари, энциклопедии, сайты синонимов и выдача поисковиков становятся его источниками, а всё найденное он сам раскладывает на определения, синонимы и контекст и запоминает.

> Версия **1.11**. Версия **1.12** уже в разработке.

## Как это работает

1. Ты пишешь слово или вопрос, например "что такое кошка" или "синонимы к слову дом".
2. Если слово незнакомо, Генгар ищет страницы про него: словари и энциклопедии (викисловарь, kartaslov, ruwiki, sinonim, gufo, academic, википедия) и выдачу DuckDuckGo с запасным Bing.
3. Из страниц он вытаскивает определения, синонимы и слова из контекста.
4. Всё сохраняется локально в `gengar_knowledge.json`, поэтому в следующий раз ответ приходит из памяти.
5. Ответ из 1-3 предложений он собирает сам, подбирая окончания и род по правилам русского языка.

Если в запросе два слова ("кошка и собака", "чем отличается..."), Генгар даёт определение каждого и ищет связь между ними.

## Что умеет

- Определения и синонимы слов, сравнение двух слов
- Три глубины поиска: `dumb` (3 сайта на слово), `normal` (10), `premium` (25)
- Поиск через `httpx` или `requests`, на выбор
- 8 цветов темы интерфейса, цвет текста ответов, переключатель анимаций
- Анимированный фон, парящий Генгар, ответы печатаются по буквам

## Установка

1. Нужен Python 3 с Tkinter.
2. Поставь зависимости:

```bash
pip install httpx requests pillow
```

3. **Скачай картинку `gengar.png` из прикреплённых файлов и закинь её в одну папку с кодом** (рядом с `gengar.py`). Без неё вместо Генгара в шапке будет эмодзи 👻.
4. Запусти:

```bash
python gengar.py
```

Структура папки:

```
gengarirt/
├── gengar.py
├── gengar.png
├── gengar_knowledge.json   (появится сам после первого ответа)
```

Если википроекты отвечают ошибкой 403, впиши свою почту в `WIKI_UA` в начале `gengar.py`.
